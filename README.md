# SDN-Project2
This project is to assign VLAN's to port, specifically odd ports to VLAN1 and even port to VLAN2. To learn about MAC's, for each MAC the switch remembers which port it is on and which VLAN it belongs to. Forward on MAC + VLAN. A rule looks like this: if dest_mac = 00:00:00:00:00:01 AND vlan = 2 → output port 3.
